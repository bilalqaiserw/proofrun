    Connect Bob & execution
    
        
      
    
      
    
      
    1. Configure your key on the server
    
      
    
        Create .env beside ProofRun's package.json.
        Add:
      
    
      
    BOBSHELL_API_KEY=YOUR_IBM_BOB_INFERENCE_KEY
    
      
    
        The browser never receives the key. Restart ProofRun after saving it. Do
        not put your key in an uploaded project.
      
    
      
    
        Use an IBM Bob Inference key. General keys also require
        BOB_TEAM_ID in the same server .env file.
      
    
      
    2. Install Bob Shell
    
      
    If it is missing, run this from ProofRun's folder:
    
      
    npm run setup:bob
    
      
    
        Complete IBM's first-run license/sign-in setup if prompted. Bob runs
        without file or command tools for this integration.
      
    
      
    3. Start Linux containers
    
      
    
        Install and start Docker Desktop with Linux containers, or use Docker
        Engine on Linux. On Windows, Docker may require WSL 2 and a restart.
      
    
      
    4. Start ProofRun
    
      
    npm start
    
      
      
    
        
    
      
    
        
    Edit proposed repair
    
        
      
    
      
    
        Edit the replacement contents. Saving creates a new diff revision;
        source is unchanged until you approve that revision.
